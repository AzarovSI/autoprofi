# ТД АВТОПРОФИ: безопасная передача проекта

Приложение: FastAPI + PostgreSQL, браузерный интерфейс на JavaScript.
Исходная точка запуска: app.main:app. Данные и пользователи находятся в
PostgreSQL, обязательные настройки сервера: DB_DSN и SECRET_KEY.
Восстановление описано в RESTORE.md; run.py создаёт SECRET_KEY автоматически.

Разделы: РНП, Юнит-экономика, Цены, Продажи, ABC, Склады, Товары, Пользователи.
Маркетплейсы: Wildberries, Ozon, Yandex. Права и бизнес-правила остаются
в исходном коде. Параметры подключения и пароли здесь намеренно отсутствуют.

Текущее состояние на 07.10.2026 включает исправления:
сохранение статусов по маркетплейсу, отображение неполных дней РНП,
фильтрацию неактивных WB-артикулов, исторические Pi, экспорты XLSX,
привязку WB-запаса в днях к последнему дню заказов и распознавание
процентного формата СПП в Excel.

Код для публикации на Perplexity: dist/public. Для независимого запуска
FastAPI отдаёт templates/index.html и static самостоятельно.
rebuild_index.py пересобирает платформенный dist из исходных файлов.
Миграции и служебные скрипты сохранены; migrate_incidents.py не запускается
автоматически и не нужен при подключении актуальной рабочей БД.

Не меняйте код сайта для переноса без необходимости. Сначала восстановите
существующую БД, настройте подключение, выполните run.py --check и запустите
приложение. Полный бэкап БД ведётся владельцем отдельно.
