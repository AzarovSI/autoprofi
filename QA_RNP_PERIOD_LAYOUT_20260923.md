# РНП и Юнит-экономика: расположение периода

Статус: локальная проверка PASS, подготовлено превью. Рабочий сайт пока не обновлён.

## Изменения

- В существующих панелях обоих отчётов поле периода перенесено в верхнюю строку справа.
- «Загрузка данных» находится непосредственно слева от периода, маркетплейсы слева.
- Поиск и остальные фильтры остались ниже.
- Переносится исходный DOM-узел с уже привязанными обработчиками. Логика календаря, запросы, расчёты, роли и API не менялись.
- Изменены views.js, app.css, dist-копии и штамп ресурсов 202609232215.
- Другие разделы не получают новую раскладку.

## Проверки

Использован локальный стенд, перехват API с синтетическими данными. Production DB не использовалась.

- Оба отчёта: календарь открывается и закрывается кнопкой, закрывается по клику вне.
- Пресеты месяца и квартала, диапазон 08–18 сентября, сохранение диапазона при переключении Ozon / WB / Yandex.
- РНП отправляет выбранные даты в исходный API; недельная Юнит-экономика сохраняет клиентскую фильтрацию.
- Переход в загрузку и обратно, поиск, выбор/очистка менеджера и статуса, раскрытие/сворачивание.
- При прокрутке панель закрепляется, календарь доступен.
- Admin видит загрузку, manager не видит; календарь доступен обеим ролям.
- Новая строка и календарь умещаются на ширинах 1550, 1280, 390, 320.
- Скриншоты desktop обоих разделов и mobile-календарь просмотрены.
- Ошибок JavaScript нет; синтаксис JS, совпадение source/dist и git diff --check проверены.

Существующее горизонтальное переполнение нижних таблиц/фильтров на узких экранах
не входит в изменение: адаптирована только новая верхняя строка и её календарь.
