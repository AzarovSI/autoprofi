# РНП: частичные данные за день

## Область изменения

- Ozon: рейтинг и отзывы создают строку даты/артикула без необходимости сначала загружать заказы. Используется канонический артикул каталога; повторный импорт обновляет только эти два поля.
- Ozon и WB: общий склад АВТОПРОФИ читается из `stock_daily` на точную дату, в том числе для отсутствующих строк заказов, только по товарам соответствующего маркетплейса.
- Повторные импорты заказов сохраняют внешние показатели даже для товаров, отсутствующих в повторном файле. Старые заказы не восстанавливаются.
- WB: в список сохраняемых внешних полей включены `spp_pct` и `price_index_pi`.
- Прогноз и среднедневные заказы для оборачиваемости WB/Ozon используют даты с фактическими значениями `orders_qty`, включая действительный ноль. День только с дополнительными показателями не считается нулевым днём заказов.
- Московская дата вычисляется на запрос, а не при старте процесса; дата входит в версию ключа кэша.
- Яндекс, источники складов маркетплейсов, интерфейс и права доступа не менялись.
