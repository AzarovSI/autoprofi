# Проверки дневных Pi

## Объём

Только WB/Ozon РНП заказы: два вложенных индекса под существующим Pi.
Основной Pi и Yandex не меняются. Исходные отчёты и базовые цены сохраняются.

## Функциональные проверки

- Дневные Pi сохраняются и обновляются при INSERT/UPDATE/DELETE исходных цен.
- Нет переноса цен с других дней, будущие значения не попадают в прошлые дни.
- Нулевая/пустая СПП и историческая оценочная СПП не дают покупательского Pi.
- Базовая цена действует по истории, граница дня определяется по Москве.
- Поправки базовой цены/категории пересчитывают затронутые артикулы.
- Поздняя загрузка второго МП, повторный импорт, rollback и параллельные импорты.
- В двух РНП один покупательский Pi Ozon/WB; исходный главный Pi неизменен.
- Месячный итог на конечную дату, не среднее и не последнее непустое.
- Серверный кэш зависит от версии Pi; при входе клиент запрашивает свежую версию.

## Браузерный чек-лист

- Ozon и WB: независимое раскрытие/сворачивание Pi и «Ср. загружаемая цена».
- Две строки, точные подписи, коэффициент с двумя знаками, прочерки.
- Сохранение раскрытия при переходе Ozon → WB → Ozon.
- Раскрытие месяца, поиск артикула, сворачивание и повторное раскрытие.
- Desktop и узкий экран: читаемые подписи, доступные кнопки, горизонтальный скролл.
- Негативные сценарии: отсутствующие цены конечного дня и загрузка только одного МП.
- Проверка ошибок JavaScript.

## Границы

Браузерные проверки выполняются на синтетических заказах и реальной локальной
таблице Pi. Данные production в тесты не копируются. Экспорт РНП по-прежнему
содержит только заказы/план/прогноз и не расширяется в рамках этой задачи.

## Результаты

- 55 unittest-проверок пройдены, включая реальные файлы WB/Ozon; пропусков нет.
- Запуск полного FastAPI на локальной БД успешен; неавторизованный RNP GET → 401.
- Playwright desktop 1440×1000: обе вложенные строки, одинаковый buyer Pi 1,50,
  разные base Pi 1,20 Ozon / 1,00 WB, исходный Pi 0,51 неизменен.
- Проверены независимые раскрытия, клавиша Enter, переключение WB/Ozon с
  восстановлением состояния, месяцы, поиск без результатов и возврат, общие
  кнопки раскрытия/сворачивания. Ошибок JavaScript нет.
- Узкий экран 390×844: новые подписи/кнопки работают, но существующая адаптация
  всей таблицы РНП имеет горизонтальное переполнение и перекрытие sticky-шапкой.
  Мобильная компоновка в этот выпуск не входит; полного mobile visual PASS нет.
- Локальный синтетический тест: 60 000 исходных строк / 500 артикулов / 60 дней,
  запись с расчётом 30 000 дневных Pi 0,698 с, чтение 30 000 строк 0,072 с.
  Транзакция теста откатилась; это не оценка производительности production.
