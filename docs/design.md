# Дизайн интерфейса

Обновлено: 07.10.2026. Источник: выгрузка Perplexity (03) + сверка с `templates/index.html`, `static/css/*.css`, `static/js/views.js`, XLSX-генераторами. При расхождении верить коду.

Задача по дизайну не даёт права менять расчёты, API или состав товаров. Макеты строить по реальному интерфейсу.

## Тема и фирменный стиль

- **Тема только светлая.** `<html data-theme="light">` в `templates/index.html`; в `static/css/app.css` нет тёмных переопределений и `prefers-color-scheme`. Тёмную тему не добавлять.
- Фирменные цвета (шапка `app.css`): красный PANTONE 485C `#EB1414` (`--accent`), почти чёрный `#16191D` (`--text`), серый PANTONE 7543C `#96A5AF` (`--text-mute`, `--flat`).
- Логотип — официальный вектор: кольцо `#ED1C24`, текст `#231F20` (`.ap-logo .ap-ac`, `.ap-logo .ap-fg`).
- Шрифт — системный стек `--sans`; числа в таблицах — `--mono` + `font-variant-numeric: tabular-nums` (`table.tbl td.num`, `.rnp-mtbl td.num`). Внешние шрифты не грузятся.

## Цвета и жирность метрик

**Юнит-экономика** (`rnp_router.py:PRODUCT_METRIC_DEFS`):
- синий `#0000FF` — себестоимость, план продаж;
- фиолетовый `#9900FF` — «Продвижение, от продаж», бледно-фиолетовый `#C58CFF` — «от заказов» (дочерняя строка);
- красный `#C0392B` — «Все удержания», `#D11414` — штрафы, `#980000` — «Прочие удержания (общие)»;
- служебные удержания и объёмы — `#16191D`; выкуп — приглушённый `#96A5AF`.
- **Жирные только** «Все удержания», «Прибыль», «Заказы, шт», «Заказы, руб» (и строка «Маржинальность, %», если она не верхний показатель). Тяжёлый жирный в остальных строках не вводить.
- Сводная (`CROSS_METRIC_DEFS`): нейтральный `#666666`, план синий, прибыль — цвет по умолчанию.

**РНП заказы** (`rnp_sales_router.py:GROUP_METRIC_DEFS`, `PRODUCT_METRIC_DEFS`):
- `#674EA7` — ДРР и реклама; `#990000` — отмены; `#1155CC` — CTR;
- `#38761D` — СПП и рейтинг; `#7F6000` — число отзывов; `#999999` — цены конкурентов; `#333333` — цена для покупателя и вложенные Pi;
- жирные: «Ср. загружаемая цена» (заголовок подгруппы «Цены»), «Индекс цены, Pi», позиция, отзывы, рейтинг, остаток МП.

## Шапка и меню

- **Шапка-карточка** (`.appbar`): sticky, высота `--header-h` 96 px (80 px на ≤ 600 px). Белая карточка рисуется `::before` с отступом, рамкой и радиусом 14 px.
- Логотип слева по центру по вертикали, отделён вертикальной линией (`.appbar .ap-logo`, ширина 170 px). Подзаголовка «Аналитика маркетплейсов» нет.
- Активный раздел — мягкая подсветка: текст `--accent-soft`, фон `--accent-bg` (8% красного) (`.nav a.active`). Яркую красную заливку не использовать.
- Справа — имя пользователя и «Выйти». ≤ 1320 px — меню сворачивается в кнопку ☰ (`.nav-toggle`, выпадающая панель `.nav.open`).
- Под шапкой — `.pagehead`: крошки «Главная / раздел», заголовок, справа контролы раздела (`#topbar-controls`).
- **Порядок меню** (итог на 07.10, `templates/index.html`, `#nav`): РНП → Юнит-экономика → Цены → Продажи, шт. → ABC → Склады → Товары → Пользователи.
  - view-id: `rnp_sales`, `rnp`, `prices`, `skus`, `abc`, `warehouses`, `catalog`, `users`.
  - «Товары» — это переименованный «Справочник» (view `catalog`), не новый раздел.
  - «Пользователи» — только admin (`data-admin`). «Склады» помечены `data-owner`, но показываются всем, пока раздел не в `OWNER_VIEWS` (`static/js/app.js:applyRoleVisibility`).
- Внутри разделов — подтабы МП (`.subtabs` / `.subtab.ozon|wb|yandex|cross`); подтаб «Загрузка данных» прижимается вправо (`.subtab-right`).

## Порядок групп в деревьях

- ECOM → ТД «АВТОПРОФИ» → прочие L1 по алфавиту; L2/L3 по алфавиту; товары по артикулу. Метрика и период порядок не меняют.
- Бэкенд: `app/util.py:l1_sort_key`, `cat_sort_key` (все деревья и XLSX). Фронт-зеркало для прайс-листа и индекса цен: `views.js:plL1Rank`, `plCompareNodes`.
  - В JS алфавит — `localeCompare('ru')`, в Python — сравнение строк в нижнем регистре. На необычных символах порядок может отличаться.
- «Не распределены по группам» — отдельная группа в самом конце.

## Таблицы

- **Юнит-экономика — только таблица**: дерево + сетка недель при любом числе недель. Без графиков, карточек-виджетов и диаграмм.
  - Значение и дельта к прошлой неделе — две подколонки одной ячейки (`.rnp-vc-v`, `.rnp-vc-d`), а не два числа в одном тексте.
  - Верхняя часть карточки группы рендерится тем же кодом и в том же порядке, что у товара. Групповые метрики — после «Выкуп, %», с разделителем.
- **0 и прочерк в дневных ячейках РНП** (`views.js:rnpsFmt`):
  - `—` — нет данных (NULL или нет строки за день); `0` — реальный ноль.
  - Загрузчик WB при существующей строке дня пишет пустые счётчики нулём, поэтому в днях с активностью «белых дыр» нет.
  - Ноль не заменять прочерком и наоборот; вчерашнее значение не подставлять.
- **Форматы чисел** (`views.js:rnpsFmt`, `rp`): штуки и рубли — целые с разделителем тысяч, без «₽»; цены — с «₽»; проценты — доля × 100 с одним знаком; Pi — всегда 2 знака.
- В «Ценах» пусто — `–` (`.sp-plan-empty`); СПП — «34,2%» с одним знаком и запятой; оценочная СПП — маркер «≈» слева, не сдвигающий число.
- **Тепловая шкала** — только дневные ячейки товара, мин/макс по видимым дням своей строки; итоги, план, прогноз, группы не окрашиваются.
- Шапки таблиц sticky (`table.tbl th`); итоговые колонки месяца — нейтральная подложка.
