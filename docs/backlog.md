## Переезд и инфраструктура

- **Бэкапы — позже на компьютер владельца** (решение 07.10.2026). Пока бэкапы идут на
  Google Диск через rclone. Владелец планирует перейти на копии на свой компьютер: нужна

- **Полного восстановления дампа рабочей БД** не было: проверка шла только на схеме
  и синтетических данных.

- **Отказоустойчивость (08.10.2026).** Сбой зоны `ru-central1-b` в Yandex Cloud остановил
  и сервер `autoprofi-web`, и кластер БД: оба в зоне b, у кластера один хост. vilka (зона a)

- **Права доступа по ролям — следующая задача (12.10.2026).** Матрица 8 ролей × 99 функций
  заполнена владельцем; сначала закрыть открытые вопросы — `docs/access_roles.md`.

## Найдено при приёмке 07.10.2026 (сверка кода с выгрузкой)

- **Схему из репозитория целиком не воссоздать.** Часть DDL применялась вручную:
  - `uploaded_by_user_id`;
  - таблицы инцидентов;
  - колонки `sales_plan.is_manual` и `prev_qty`.

  В `app_schema_migrations` записан только daily Pi. Источник истины — рабочая БД:
  `recovery/schema_contract.json` и дамп схемы.
- **Масштаб СПП в прямых ценах WB/Ozon** определяется по величине числа
  (> 1 → делится на 100). Это расходится с общим правилом «не угадывать по величине».
  Проверить на реальных файлах, ничего не менять без согласования.
- **WB «Рейтинг и отзывы».** После правки 07.10 XLSX читается через openpyxl,
  запасного чтения через calamine нет. Если придёт файл с `SharedStrings.xml`
  (заглавная S), чтение может упасть. Риск не проверен.
- **Реклама Ozon за несколько дней.** Если в отчёте период из нескольких дней,
  вся сумма расхода записывается в каждый день диапазона.
- **Яндекс.** Повторная загрузка «Аналитики продаж» удаляет строки-заготовки
  с остатками FBY за эти даты.
- **Журнал загрузок:**
  - PriceVA WB пишется с тем же `period_kind='competitors'`, что и Ozon,
    поэтому виден в журнале Ozon, а не WB;
  - у остатков Ozon по складам нет своего фильтра.

- **Цена продажи в «Складах».** `PRICE_CTE` в обоих роутерах складов сортирует
  `fact_monthly` по `month DESC` без года. На стыке лет «последний месяц» может
  оказаться прошлогодним.
- **ДРР Ozon и Яндекса в ABC — подтверждено 07.10.2026:** на копии рабочих данных ABC
  показывает ДРР Ozon −7,6%, Яндекс −1,2%. `abc_router.py` обещает модуль `promo_total`,
  но `abc_module.js` знак не снимает. Исправлять — по согласованию.
- **Pi в РНП и в «Цены → Индекс цен» могут расходиться** для группы АВТОПРОФИ:
  индекс цен учитывает оценочную СПП, дневной Pi — нет.
- **Юнит-экономика.** Подпись `drr_pct` — «ДРР % к заказам», а по коду это
  promo / выручка: у Ozon со знаком минус, у WB всегда 0. «Доля A-товаров» берёт
  `abc_revenue` из MPPROFIT, хотя раздел ABC эти колонки игнорирует.
