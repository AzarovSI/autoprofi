# РНП WB: пустой статус без активности

## Область изменения

Только WB. Артикул с NULL, пустым или пробельным статусом исключается из
дерева, итогов и undistributed, если за выбранный период не было заказов
(штуки или рубли), рекламных расходов или остатка WB.
Отзывы, цены и общий склад сами по себе не являются активностью.
При наличии активности обычная проверка распределения сохраняется.
CORE/NEW/? и прочие назначенные статусы не затрагиваются.
Правило сохранённого статуса «-» не меняется; Ozon/Yandex не меняются.
Источник данных и импортёры не меняются. Cache key v6.
